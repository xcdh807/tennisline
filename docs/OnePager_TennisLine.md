# TennisLine — 口袋里的鹰眼
**AI 网球轨迹追踪与数据分析 Web App** · 个人项目 · 产品负责人（0→1）

---

### ⚡ 一句话
打开手机浏览器即可拍摄或上传网球视频，在**本地实时 AI** 识别球体、绘制轨迹，并输出球速 / 旋转 / 落点 / 界内出界判定，让每一位业余球员以**零硬件成本**获得接近 ATP 鹰眼的体验。

| 决策 | 为什么这么做 | 效果 |
|---|---|---|
| **Web-First 而非原生 App** | 0 下载门槛 · 全平台触达 · 迭代周期从"周"降到"小时" | 安卓/iOS 同步上线 |

### 🔬 核心技术亮点

**浏览器内实时计算机视觉管线**（`useVideoAnalysis.ts`）：
```
video frame → 320×240 缩放 → 灰度帧差 → 形态学膨胀 → motion mask
            → HSV 颜色筛选（网球荧光黄 H:18-48）→ 18px 网格聚类
            → 形状校验（尺寸/长宽比/密度/圆度）→ 评分 → 物理约束 Tracker
            → 速度/旋转/落点/击球类型/回合数
```
**"先运动再颜色"** 策略，把误检率从 ~60% 降到 **~15%**（小样本估算）。

**数据安全**：Supabase 全表 RLS + Storage 按 userId 隔离 + 删除联动清理 + 保存失败自动降级本地下载。

### 🌟 可讲的 3 个小故事（面试加分）

1. **"显示 `--` 而不是 `0`"** ——当 AI 未检测到球时，数值显示两个短横而非 0。原因：演示中发现用户看到 0 会问"为什么不动"，而 `--` 是 BBC/NBC 转播惯例，符合专业仪表盘心智。**小决策，大信号**。
2. **"保存失败自动下载"** —— Supabase 上传失败不报错，静默降级为浏览器本地下载。**产品可靠性 > 功能先进性**。
3. **"双仓库推送"** —— GitHub + Gitee 同步，解决国内访问速度，一次 `git push` 同时到两个远程。
