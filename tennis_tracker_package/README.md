# Tennis Ball Tracker

## 项目简介

这是一个基于OpenCV的网球跟踪程序，能够自动检测视频中的网球位置并记录轨迹。

## 功能特点

- 自动检测网球位置
- 实时跟踪球的轨迹
- 过滤静止物体
- 生成输出视频和坐标文件
- 支持批量处理多个视频文件

## 环境要求

- Python 3.7+
- OpenCV 4.5.0+
- NumPy 1.19.0+

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 准备视频文件

将需要处理的 `.MOV` 格式视频文件放入 `VideoInput` 文件夹中。

### 2. 运行程序

```bash
python process_all_mov.py
```

### 3. 查看结果

程序会自动处理 `VideoInput` 文件夹中的所有视频，并将结果保存到 `output_mov_videos` 文件夹中。

输出文件包括：
- `*_output.mp4`：带有网球标记的输出视频
- `*_output_coords.txt`：球的轨迹坐标文件

## 输出说明

### 视频输出
- 红色圆圈：标记检测到的网球位置
- 坐标文本：显示球的实时坐标
- 红色线条：球的运动轨迹

### 坐标文件格式
```
帧号,x坐标,y坐标
1,100,200
2,105,210
...
```

## 算法说明

### 检测算法
1. **颜色过滤**：基于HSV颜色空间检测网球
   - H范围：[30, 37]
   - S范围：[57, 122]
   - V范围：[230, 255]

2. **形态学操作**：腐蚀和膨胀去除噪声

3. **轮廓分析**：
   - 面积过滤：10-500像素
   - 宽高比：0.5-1.5（接近圆形）
   - 圆形度计算

4. **运动检测**：过滤静止物体

5. **综合评分**：选择最佳候选轮廓

## 注意事项

1. 确保视频中的网球颜色清晰可见
2. 光线条件会影响检测效果
3. 背景应尽量简单，避免与网球颜色相似的物体
4. 建议在光线充足的环境下拍摄视频

## 故障排除

### 问题1：检测不到球
- 检查颜色范围是否合适
- 调整面积过滤参数
- 确保视频质量良好

### 问题2：误检测太多
- 增大运动检测阈值
- 调整圆形度要求
- 缩小颜色范围

### 问题3：轨迹不连续
- 降低运动检测阈值
- 调整综合评分权重
